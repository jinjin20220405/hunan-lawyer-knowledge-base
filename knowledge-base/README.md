## 📝 文档命名规范

所有文档使用Markdown格式，命名规则：
- 使用中文标题
- 使用`.md`扩展名
- 例如：`中华人民共和国律师法.md`

## 🔧 工具使用

### 转换Word文档
```bash
python tools/batch-convert.py
```

### 爬取网站内容
```bash
# 检查更新
python tools/crawler.py --check

# 下载更新
python tools/crawler.py --download
```

# 将新增的md文件放入对应目录即可

1. **新增文档**：直接将md文件放入对应目录
2. **更新网站内容**：运行爬虫工具
3. **查询知识**：通过Skill提问即可
