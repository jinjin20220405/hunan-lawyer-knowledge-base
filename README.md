**版本**: v1.0
**创建时间**: 2026-01-16

## 系统简介

本系统是一个专业的律师行业规范管理工具，帮助律师事务所和律师从业人员实现规范化的执业管理和风险控制。即使你是行业小白，也能通过本系统达到专家级的管理水平。

### 核心功能

✅ **知识库管理** - 集中管理法律法规和行业规范
✅ **收案审查** - 全面的风险评估和合规审查
✅ **利益冲突检查** - 系统性的冲突排查
✅ **违规行为认定** - 准确的违规判断和整改建议
✅ **文书生成** - 标准化的申请书和报告生成
✅ **新人培训** - 系统性的执业规范培训指导
✅ **自动更新** - 一键检查和下载最新规范

## 快速开始

### 1. 系统结构

```
lawyer-Knowledge Base/
├── knowledge-base/          # 知识库目录（存放所有规范文档）
│   ├── 01-法律法规/
│   ├── 02-行业规范/
│   ├── 03-执业指引/
│   ├── 04-行政文件/
│   ├── 05-办事指南/
│   └── 06-地方规范/
├── tools/                   # 工具脚本目录
│   ├── update.py           # 更新工具（主要工具）
│   ├── simple-convert.py   # Word转Markdown工具
│   └── DOWNLOAD_NEEDED.md  # 待下载文章清单
├── skills/                  # Skill目录
│   └── hunan-lawyer-management.skill.md  # 核心Skill文件
└── README.md               # 本文件
```

### 2. 初始设置

系统已预置以下文档：
- **法律法规**（4篇）: 中华人民共和国律师法、律师执业管理办法等
- **行业规范**（1篇）: 湖南省律师协会章程

### 3. 检查知识库状态

```bash
cd "H:/lawyer-Knowledge Base"
python tools/update.py --status
```

### 4. 检查更新

```bash
python tools/update.py --check
```

该命令会：
- 检查知识库当前状态
- 对比已知文章列表
- 生成待下载文章清单（`tools/DOWNLOAD_NEEDED.md`）

### 5. 下载新文章

系统提供两种下载方式：

#### 方式一：使用Claude MCP webReader工具（推荐）

1. 查看待下载清单：
   ```bash
   cat tools/DOWNLOAD_NEEDED.md
   ```

2. 在Claude Code中逐个执行：
   ```
   webReader https://www.hnlx.org.cn/show_n.php?t=2&id=11528
   ```

3. 将输出内容保存为对应的Markdown文件

#### 方式二：手动下载

1. 访问湖南律师网：https://www.hnlx.org.cn
2. 找到对应文章
3. 复制内容并粘贴到Markdown文件
4. 保存到对应的分类目录

## 使用律师管理Skill

### Skill功能模块

本系统的核心是 `hunan-lawyer-management.skill.md`，提供以下功能：

#### 1️⃣ 收案审查和风险控制

**使用场景**：接受新案件前的风险评估

**示例对话**：
```
用户: 我准备接一个民间借贷案件，标的额500万元，对方当事人是我们市的某银行，这个案件有什么风险吗？

Skill: [基于知识库搜索，提供]：
- 利益冲突审查清单
- 代理风险评估
- 收费合理性分析
- 风险防范建议
```

#### 2️⃣ 利益冲突审查

**使用场景**：检查是否存在利益冲突

**示例对话**：
```
用户: 我们所正在代理某银行的案件，现在又有新的客户想让我们代理起诉该银行，可以吗？

Skill: [搜索相关规范，提供]：
- 利益冲突认定标准
- 回避要求
- 解决方案建议
```

#### 3️⃣ 律师违规行为认定

**使用场景**：判断执业行为是否违规

**示例对话**：
```
用户: 有个律师私下和当事人约定风险代理收费比例达到40%，这算违规吗？

Skill: [检索相关法规，提供]：
- 违规事实认定
- 法律依据（具体条款）
- 违规后果说明
- 整改建议
```

#### 4️⃣ 申请书/报告生成

**使用场景**：生成各类法律文书

**示例对话**：
```
用户: 帮我生成一份建设工程施工合同纠纷案件的收案审查报告。

Skill: [基于规范要求，生成]：
- 标准化报告模板
- 必备内容清单
- 填写指导说明
```

#### 5️⃣ 新律师培训

**使用场景**：为新律师提供系统培训

**示例对话**：
```
用户: 我需要给新来的实习律师进行培训，主要讲执业规范，有哪些重点内容？

Skill: [整理培训大纲，提供]：
- 系统化培训模块
- 重点内容摘要
- 案例分析
- 考核要点
```

#### 6️⃣ 统一收案收费管理

**使用场景**：建立规范的收案收费制度

**示例对话**：
```
用户: 我们所想要建立统一的收案收费管理制度，应该包含哪些内容？

Skill: [提供]：
- 管理制度框架
- 操作流程规范
- 必备条款清单
- 风险控制要点
```

#### 7️⃣ 重大事项报告

**使用场景**：处理重大事项的报告程序

**示例对话**：
```
用户: 我们接了一个群体性案件，需要向哪里报告？怎么报告？

Skill: [提供]：
- 重大事项判断标准
- 报告对象和时限
- 报告内容要求
- 标准报告模板
```

#### 8️⃣ 执业行为禁令

**使用场景**：了解执业中的禁止行为

**示例对话**：
```
用户: 律师在执业中哪些行为是绝对禁止的？

Skill: [提供]：
- 禁止行为清单
- 法律依据
- 违规后果
- 例外情况说明
```

#### 9️⃣ 内部管理机制

**使用场景**：建立健全内部管理制度

**示例对话**：
```
用户: 我们所想要完善内部管理制度，应该从哪些方面入手？

Skill: [提供]：
- 制度建设框架
- 各模块要点
- 制度文本模板
- 实施建议
```

## 添加新文档

### 方式一：直接放置

1. 将新的Markdown文件直接放入对应的分类目录
2. 文件命名格式：`文档标题.md`
3. 运行 `python tools/update.py --status` 确认

### 方式二：使用添加命令

```bash
python tools/update.py --add "https://www.hnlx.org.cn/show_n.php?t=2&id=12345" \
  --title "新规范名称" \
  --category "02-行业规范"
```

然后使用webReader工具下载内容。

## 常见问题

### Q: 如何使用Skill？

A: 在Claude Code中，直接提出相关问题即可。Skill会自动激活并提供专业回答。

### Q: 知识库文档不够怎么办？

A: 运行 `python tools/update.py --check` 检查更新，或手动添加文档到对应目录。

### Q: 如何确保内容是最新的？

A: 定期访问湖南省律师协会官网（https://www.hnlx.org.cn），使用更新工具下载最新规范。

### Q: 可以自定义添加文档吗？

A: 可以。直接将Markdown文件放入对应分类目录即可。

### Q: Windows下命令行显示乱码怎么办？

A: 这是Windows控制台GBK编码问题，不影响功能。如需查看，可使用 `> output.txt` 将输出重定向到文件。
